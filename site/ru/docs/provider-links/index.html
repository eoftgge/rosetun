Ссылки для провайдеров

С 0.5: регистрация схемы в Debian и сокет Linux.

Кнопка на странице провайдера может открыть Rosetun с заполненной подпиской: rosetun://add/<ссылка подписки>, ссылка как есть (rosetun://add/https://example.com/sub) или percent-кодированная (rosetun://add/https%3A%2F%2Fexample.com%2Fsub). Необязательное #имя в конце предлагает название подписки (rosetun://add/https://example.com/sub#Example). Rosetun только показывает окно Добавить подписку со ссылкой, названием и хостом провайдера; ничего не загружается и не добавляется, пока вы не нажмёте Добавить. Ссылка на уже добавленную подписку только показывает её.

Установщик Windows регистрирует схему для всех пользователей. Пакет Debian регистрирует её через свой файл .desktop (x-scheme-handler/rosetun). Запущенный Rosetun получает ссылку от следующего запуска по каналу, который может открыть только ваша учётная запись: именованный канал на Windows, сокет в $XDG_RUNTIME_DIR на Linux.

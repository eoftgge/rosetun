- **Правила маршрутизации** для программ, сайтов, IP-адресов, подсетей, списков и **групп правил**, каталог **Шаблоны** и действия **Через VPN**, **Напрямую** и **Блокировать**.
- **Направления:** правило может вести свой трафик через другую страну или конкретный узел, а остальное идёт через сервер с главного экрана. Выбор страны или узла в правиле создаёт направление во вкладке **Направления**; там можно сменить его узел и включить запасной: любой узел той же страны. Если узел направления пропал, его правила блокируют трафик и никогда не идут напрямую.
- **Списки:** GeoIP и GeoSite (файлы Xray `.dat`) и наборы правил sing-box (`.srs`) и свои текстовые списки из файла или по ссылке. Список по ссылке скачивается заново, только если он изменился (`ETag` / `Last-Modified`).
- **Отмена:** Ctrl+Z отменяет изменения во вкладке «Правила» по шагам, **Вернуть** возвращает правила, применённые к подключению, а Del удаляет выделенное правило без вопроса.
- **Временные правила:** добавьте правило только до отключения; оно применяется сразу, отображается рядом с активным набором на экране подключения и никогда не сохраняется.
- **Соединения** на вкладке «Трафик»: при подключении видно, куда программы соединяются прямо сейчас, по программам, каким маршрутом пошло каждое соединение и почему (какое правило, список или правило по умолчанию). Оттуда же можно создать правило или закрыть соединение. Список хранится только в памяти, только для учётной записи, которая подключилась, и очищается при отключении; на диск и в журнал он не попадает.

## Группы и шаблоны {#groups}

Группа объединяет несколько сайтов, программ, IP-адресов или списков под одним названием, одним переключателем и одним назначением. Группа занимает одну строку в таблице и работает как обычное правило: её можно перетаскивать, выключать, экспортировать и отменять изменения через Ctrl+Z.

- **Каталог шаблонов:** кнопка **Шаблоны** рядом с **+ Добавить правило** открывает готовые пресеты (Российские сайты, Мессенджеры, YouTube, Торренты, ИИ-сервисы, Соцсети, Стриминг и музыка, Игры и лаунчеры). Для каждого шаблона можно посмотреть состав и сразу выбрать маршрут. После добавления шаблон становится обычной группой, которую можно свободно менять.
- **Свои группы:** выделите два или больше правил в таблице и нажмите **В группу**, либо создайте новую группу кнопкой **Новая группа** в окне шаблонов.
- **Просмотр и правка:** нажмите на стрелку у группы (или дважды нажмите на строку), чтобы раскрыть список условий прямо в таблице. Оттуда можно убрать отдельное условие, открыть редактор группы или разгруппировать её обратно в отдельные правила.

## Проверка адреса {#test}

Во вкладке «Правила» введите сайт, IP-адрес или программу в поле **Поиск или проверка адреса**. Под строкой поиска появится ответ, куда набор в работе это отправит: маршрут, а за ним правило, список или правило по умолчанию. Подключение не нужно, в сеть ничего не уходит. Номер правила в строке ведёт к нему в таблице. Временные правила текущего подключения учитываются.

Часть ответов остаётся открытой: строка так и говорит и показывает, что скажут правила в остальных случаях. Частный адрес при включённой **Локальной сети** зависит от вашей сети, которую знает только служба. По одному имени программы не найти правило по полному пути, а по имени сайта правило по IP-адресу. Список, который здесь не прочитать, например загруженный `.srs`, тоже оставляет ответ открытым.

CLI: `rosetun rules test <адрес|программа>` печатает ту же строку и завершается с кодом 0, в том числе при открытом ответе. Ввод, который не сайт, не IP-адрес и не программа, завершается с кодом 2.

## Программы на Linux {#programs-on-linux}

**Правила по программам на Linux** имеют цену. Чтобы найти программу соединения, sing-box читает процессы всех учётных записей, поэтому сеанс с включённым правилом по программе даёт своему ядру `CAP_SYS_PTRACE` и `CAP_DAC_READ_SEARCH`: почти root для того, кто захватит ядро. Без такого правила у ядра нет ни того, ни другого. Там, где служба не может их дать (например, вне своего юнита systemd), подключение с таким правилом отклоняется с указанием причины.

Известная ошибка sing-box на Linux: соединение иногда приписывается не той программе ([SagerNet/sing-box#4501](https://github.com/SagerNet/sing-box/issues/4501), открыта; на Windows не относится). Поэтому правило «Напрямую» для программы может изредка пропустить мимо туннеля чужое соединение, и при включённом kill switch тоже: ядру kill switch выход разрешает. Соединение, программа которого не найдена, не подходит ни под одно правило по программе и идёт по следующим правилам. Если это важно, используйте правила по сайтам и IP, а по умолчанию оставьте «Через VPN» без правил «Напрямую» по программам.

## Направление через другое направление {#two-hop}

Экспериментально.

Направление может подключаться к своему серверу через другое направление, и трафик идёт по пути A → B. Оба направления прокси одного подключения.

1. Добавьте серверы A и B и создайте их направления на вкладке **Направления**.
2. Откройте направление B. В поле **Подключаться через** выберите направление A и сохраните. Путь читается как **A → B**.
3. Укажите **B** в нужном правиле. Для работающего подключения нажмите **Применить**.

Меняется только трафик, который выбирает это правило. Весь трафик компьютера через B не идёт. В режиме системного прокси приложение должно использовать локальный прокси; остальной трафик остаётся под прежними правилами и защитой.

**Напрямую** в редакторе B возвращает обычное подключение к серверу B. Это не назначение правила **Напрямую**. **Отмена** сбрасывает изменения в редакторе. Если **Применить** не удалось, возвращаются сохранённые правила, DNS и пути направлений; временные правила остаются. Направление, через которое подключается другое, удалить нельзя: сначала измените путь зависимого направления.

Ограничения:

- Ровно два звена. Направление не может подключаться через себя, циклов и третьего звена нет.
- B это прокси HTTP, HTTPS или SOCKS5, а его сервер задан IPv4- или IPv6-адресом, не именем. HTTPS по-прежнему проверяет сертификат; где нужно, укажите ожидаемое имя TLS-сервера.
- A может быть любым сервером, до которого дотянется sing-box, в том числе работающим через Xray, например VLESS с REALITY при Xray в режиме **Автоматически**. B через Xray и фрагментация TLS для такого пути не работают.
- Имя B Rosetun сам не разрешает: адрес B должен быть задан числом. Имя A разрешается по обычным правилам. DNS для сайтов, которые вы открываете, следует вашим настройкам DNS, поэтому функция не обещает, что весь DNS идёт через B.
- UDP, в том числе QUIC, которое правило направляет через B, блокируется. Оно не переходит на A и не уходит напрямую. Остальные правила работают как раньше.
- Отсутствующее направление, недоступный прокси, неверные учётные данные или неудачное рукопожатие HTTPS не переключают на более короткий путь. После изменения подписки, запасной страны или режима служба проверяет путь заново.
- Задержка B измеряет весь путь A → B. IP-адрес выхода на экране подключения описывает основной маршрут, а не публичный адрес B.

Поле **Подключаться через** появляется, когда доступно хотя бы одно промежуточное направление. Если путь блокирует только фрагментация TLS, редактор предложит её выключить. Если сохранённый путь стал недоступен, можно выбрать **Напрямую**.

## Экспорт и импорт {#exchange}

На вкладке «Правила» выберите нужный набор в списке («Основной»), затем откройте многоточие рядом с ним. Здесь доступны экспорт всех или выделенных правил этого набора и импорт. Набор не обязательно делать активным. Экспортируйте документ в буфер обмена или в JSON-файл. Для импорта откройте то же меню и выберите файл или буфер обмена. На Linux файловые диалоги открываются через XDG Desktop Portal. Если диалог недоступен, используйте буфер обмена. В предпросмотре выберите существующий набор и нажмите «Добавить» или «Заменить», либо выберите «Новый набор», укажите имя и нажмите «Импорт». Новый набор создаётся только при подтверждении и не становится активным автоматически. Дубликаты пропускаются. Весь импорт, включая правило по умолчанию и ссылки на списки, отменяется одним Ctrl+Z.

Перед импортом показаны назначения, дубликаты, неверные и выключенные правила, недоступные серверы. Правило по умолчанию меняется только после отдельной отметки. Для широких правил «Напрямую» есть предупреждение. Через ссылку `rosetun://` импортировать правила нельзя.

Содержимое списков не передаётся. Источники по URL включаются только после подтверждения с показом хостов: ссылки могут содержать ключи доступа. Без подтверждения правила по спискам приходят выключенными с требованием выбрать список. Списки из файла требуют указанный файл, правила по ним тоже выключены. Импорт не скачивает списки.

Имена программ переводятся между Windows и Linux: `firefox.exe` становится `firefox`, регистр Linux сохраняется. Пути другой системы остаются выключенными. Сервер сопоставляется по точному имени, названию подписки и стране. Если совпадения нет или оно неоднозначно, правило получает «Через VPN» с предупреждением.

Формат обмена независим от настроек: `format: "rosetun-rules"`, `version: 1`, версия приложения, исходная система, необязательное правило по умолчанию, правила и используемые списки. В документ не входят внутренние ID правил, списков и серверов, адреса и порты серверов, ключи и пароли, содержимое и хеши списков, время обновления. Ссылки на списки задаются номерами внутри документа с нуля. Неизвестные поля документа и версии отклоняются; неверные отдельные правила показываются в отчёте и пропускаются. Пределы: 4 МиБ и 10 000 правил или списков.

```
{
  "format": "rosetun-rules",
  "version": 1,
  "exported_by": "0.6.0",
  "system": "windows",
  "default_target": "proxy",
  "rules": [
    {"enabled": true, "matcher": {"domain": {"suffix": "example.com"}}, "target": "proxy"},
    {"enabled": true, "matcher": {"ip_cidr": "192.0.2.0/24"}, "target": "block"}
  ],
  "lists": []
}
```

CLI: `rosetun rules export [--selected-ids 1,2] [--with-list-urls] [ФАЙЛ|-]`; `rosetun rules import [--replace] [--yes] ФАЙЛ|-`. Экспорт без имени файла пишет в стандартный вывод. Импорт печатает предпросмотр и спрашивает перед сохранением; `--yes` подтверждает правила и сохраняет прежнее правило по умолчанию. Для его замены есть отдельный интерактивный вопрос. При чтении документа из стандартного ввода подтверждение читается с терминала. Храните документ со ссылками на списки как секрет и проверяйте правила «Напрямую» перед импортом.

ROSETUN FOR YOUR USERS

For providers

A regular subscription. One button to add it.

A button on your website

Format: rosetun://add/<subscription URL>#name. The HTTP(S) URL can be raw or percent-encoded as a whole. The optional name is percent-decoded and limited to 64 characters. The full link is limited to 8192 bytes.

<a href="rosetun://add/https%3A%2F%2Fprovider.example%2Fsubscription%2Fdemo#Example">Add to Rosetun</a>

Once Rosetun is installed, Windows opens the link in the app. Users see an add dialog with the provider host. Fetching and adding start only after confirmation. An existing subscription opens its card; a link does not replace an open dialog.

Use HTTPS. An HTTP subscription sends its token without encryption. Escape ampersands as &amp; in raw HTML.

Formats and servers

One URI per line, plain or base64. Xray JSON: a configuration object or an array of configurations; each supplies the supported outbound tagged proxy, or the first supported outbound. sing-box JSON: an object with outbounds; service entries selector, urltest, direct, block and dns are skipped. This imports servers, not the entire routing configuration.

VLESS, VMess, Trojan, Shadowsocks, Hysteria2. TCP, WebSocket, gRPC, HTTPUpgrade; XHTTP (SplitHTTP) through Xray. Unencrypted transport, TLS and REALITY. Hysteria2 uses QUIC over UDP, with Salamander and port hopping.

Unsupported: Clash YAML, encrypted Happ links, XHTTP with a separate download server, mKCP, QUIC transport for TCP protocols, HTTP/2, VLESS encryption and Shadowsocks plugins. Unsupported nodes are skipped; reasons appear in the card’s import report. Import fails if no usable nodes remain. The subscription response is limited to 5 MiB after decompression.

Response headers

HeaderHandling
subscription-userinfoupload and download: bytes; total: byte limit; expire: Unix time in seconds. Zero total and expire mean no limit or expiry. Usage and expiry appear on the subscription card.
profile-titleSubscription title, up to 128 characters. Plain text or base64:…; used on import when the user has not supplied a name.
content-dispositionFallback title from filename or UTF-8 filename*. Up to 128 characters; profile-title takes precedence.
profile-update-intervalInteger hours. Automatic updates clamp the interval to 1–168 hours; the default is 12 hours. Users can disable automatic updates.
support-url / profile-web-page-urlSupport and account links on the card. HTTP(S) only; text is limited to 2048 characters before URL validation.
announceAnnouncement on the subscription card: plain text or base64:…, up to 1000 characters.
x-hwid-max-devices-reached / x-hwid-not-supported / x-hwid-limitA case-insensitive true stops parsing with a device-limit error; announce accompanies the error.

Control and bidirectional formatting characters are removed from display text. Invalid metadata values are ignored. The same metadata is read from # key: value comments in URI lists. The routing header is not processed and does not install rules.

What your server receives

The default is User-Agent: Rosetun/<version>; users can override it. With “Send device ID” enabled, requests include x-hwid, x-device-os, x-ver-os and x-device-model. If device information cannot be obtained, the request proceeds without it.

Sharing is on by default and can be disabled per subscription, or with --no-hwid in the CLI. New subscriptions use an ID specific to the subscription server host: paths, tokens and ports do not change it. Different hosts receive different IDs. Subscriptions added before 0.4 retain their previous shared ID. OS version and model are limited to 64 printable ASCII characters; other characters become ?.

Test your subscription

  1. Install the current release and open the add button.
  2. Check the host, confirm the import and check servers, title, usage, expiry and card links.
  3. Refresh the subscription. For errors, open the card and import report details.
  4. Prepare a sanitized response and headers to reproduce the problem. Include the Rosetun version, expected behavior and error text. Do not send tokens, HWIDs, real addresses or keys.

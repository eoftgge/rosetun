Stable release: 0.5.1 · Windows and Linux.

Linux support

Distributions (amd64, glibc 2.36 or newer): Debian 13 is verified by the system test matrices. Ubuntu 24.04+, Linux Mint 22+ and other Debian/Ubuntu derivatives with this glibc or newer, systemd, nftables and polkit are expected to work with the same .deb; manual Ubuntu verification is pending.

The Arch Linux binary recipe rosetun-bin is available in the repository; AUR publication and runtime verification are pending. See installation and updates.

Systems without systemd and Flatpak, Snap and AppImage packages are unsupported: Rosetun needs a privileged system service and access to the host firewall and TUN device.

Linux does not have these yet:

  • file dialogs: a QR code is read from the clipboard only, and there is no screen capture;
  • Collect report and the buttons that open a folder (see Troubleshooting);
  • the system proxy and packet interception checks in System check;
  • a remembered window position.

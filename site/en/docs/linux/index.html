Linux support

Since 0.5: all Linux support on this page.

DesktopTraySystem proxy settings
KDE Plasma, Wayland and X11YesChanged by Rosetun (kioslaverc)
GNOMEOnly with an extension that provides a tray. Without a tray, closing the window closes the programChanged by Rosetun (gsettings)
OthersWhere a tray host answers; not testedRosetun shows the address to enter yourself

The table says what the code does. Rosetun was checked by hand on GNOME, and not yet on KDE Plasma.

Linux does not have these yet:

  • file dialogs: a QR code is read from the clipboard only, and there is no screen capture;
  • Collect report and the buttons that open a folder (see Troubleshooting);
  • the system proxy and packet interception checks in System check;
  • a remembered window position.

MADE FOR YOUR ROUTINE

One connection. More choice.

01

Connection protection

The kill switch blocks traffic when the tunnel drops while the service is running. Experimental Lockdown keeps traffic blocked without a connection and after a restart.

02

Your rules

Send apps, websites and IP addresses through the VPN, connect directly or block them. Use GeoIP, GeoSite and your own lists. Temporary rules last until you disconnect.

03

More than one exit

Choose another country or server for an individual rule. If its exit server disappears, that traffic is blocked and never falls back to a direct connection.

04

Subscriptions at hand

Add a subscription with a link, a QR code or a rosetun:// button on your provider’s site. You can turn off device ID sharing for each subscription.

05

Connection choices

VLESS, VMess, Trojan, Shadowsocks and Hysteria2. sing-box and Xray engines, REALITY and XHTTP. See the provider page for transports and limitations.

06

Privacy without promises

No telemetry. The app contacts your provider, servers, DNS, lists, GitHub and network check services. Connections stay in memory until you disconnect and are not written to disk.

Rosetun protects against accidental leaks, not malware running under your account. Without Lockdown, a service crash removes the block. Lockdown has only been tested on Windows 11; third-party firewalls, antivirus software, sleep and hibernation are untested. Network requests and protection model

Verify the installer

The installer has no Windows code-signing certificate yet. Compare its SHA-256 with the line below and SHA256SUMS.txt from the release.

Get-FileHash .\rosetun-VERSION-setup.exe -Algorithm SHA256

SHA256SUMS.txt

SHA256SUMS.txt: checksum is listed in the release file

For public tagged releases, the workflow creates an installer provenance attestation. Verify it with GitHub CLI. This verifies build provenance; it is not a Windows code signature.

gh attestation verify .\rosetun-VERSION-setup.exe --repo eoftgge/rosetun

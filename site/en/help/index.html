Help and FAQ

Install and connect

  1. Download and verify the installer. Windows 11 x64 is required. Windows 10 is untested.
  2. Run the installer and approve the administrator prompt. The installer is unsigned: if SmartScreen shows “Windows protected your PC”, after verifying the file choose “More info”, then “Run anyway”.
  3. Open Rosetun and add a subscription URL from your provider. Rosetun does not supply VPN servers.
  4. Select a server and connect. Rules choose what uses the VPN, connects directly or is blocked.

Choose an installation folder outside user profiles that ordinary users cannot modify.

Lockdown and restoring network access

Lockdown is experimental. It blocks internet access outside the tunnel, even without a connection and after a restart. Turning it on or off in the Protection card requires confirmation and administrator rights. The kill switch stays on while Lockdown is enabled.

If there is no network access and Rosetun will not open, open Windows Terminal as administrator and run: 

rosetun reset-firewall

This removes Lockdown without a running service. Once Lockdown is removed, direct internet access becomes possible. Uninstalling Rosetun also removes Lockdown. If the command is not found, open a terminal in the Rosetun installation folder you selected and run .\rosetun.exe reset-firewall.

For Wi-Fi with a sign-in page, temporarily turn off Lockdown, sign in or fix the clock, connect and enable Lockdown again. Lockdown cuts off Hyper-V networking; WSL2, Docker Desktop, Windows Sandbox and the mobile hotspot can also lose access. Turn off Lockdown while you need them.

Only Windows 11 has been tested. Third-party firewalls, antivirus software, sleep and hibernation are untested. The kill switch remains the primary protection. Lockdown does not protect against malware running under your account.

Frequently asked questions

A website will not open after connecting

Restart the browser: it has its own DNS cache, separate from Windows.

Another VPN or zapret interferes with the connection

Disconnect the other VPN in TUN mode and retry. If you use zapret, exclude your VPN server addresses in its settings.

Where do I start troubleshooting?

Open Settings → Service and logs → System check. It checks the clock, system proxy, other VPNs, packet interception and DNS substitution. It runs automatically after a failed connection. It changes nothing but does make network requests.

What does “No network connection” mean?

Check Windows networking. With reconnect on disconnect enabled, Rosetun waits for the network to return while the kill switch blocks traffic as long as the service is running.

The installer reports access to a protected folder

If ordinary users can modify the Rosetun folder, uninstall and install again. Do not grant access to the service folder through the “Continue” button in Explorer.

Collect a report

In Settings → Service and logs, select “Collect report”. The text file contains versions, settings without secrets, connection state, system checks and logs. The system check makes network requests.

Rosetun removes IP addresses, URLs, domains, email addresses, keys, passwords, server, subscription, list and rule set names, and your Windows account name. Review the file yourself before sharing.

In Issues, attach the report, steps to reproduce, expected behavior and error text. Do not attach subscription URLs or configurations containing secrets. Report vulnerabilities privately using the footer link.

Update or uninstall

Rosetun offers new versions but never downloads or installs them itself. Download the new installer from Releases, verify it and run it. When the settings format changes, Rosetun keeps a copy of the previous file alongside it; this copy also contains subscription URLs.

Uninstall Rosetun through Windows apps. Settings in %APPDATA%\Rosetun are kept by default; the uninstaller can remove settings, subscriptions and rules.

# Rosetun

Rosetun: VPN-клиент для Windows на базе sing-box. Служба Windows держит kill switch и замок DNS; правила разделяют трафик по программам и сайтам, а подписки провайдеров поставляют серверы.

**Альфа-версия:** ошибки возможны. Настройки могут сбрасываться между альфа-версиями.

## Возможности

- **Kill switch** блокирует трафик при потере туннеля. Без него замок DNS не выпускает системный DNS мимо туннеля весь сеанс, даже пока ядро перезапускается.
- **Правила маршрутизации** для программ и сайтов, **Быстрые шаблоны** и действия **Через VPN**, **Напрямую** и **Блокировать**.
- Подписки провайдеров: списки ссылок в обычном виде или в base64, Xray JSON и sing-box JSON. **Отправлять ID устройства** (HWID) можно включить для панелей, которым он нужен.
- Серверы VLESS, VMess, Trojan и Shadowsocks; транспорты TCP, WebSocket, gRPC и HTTPUpgrade; режимы без шифрования транспорта, TLS и Reality.
- **DNS через туннель** с настраиваемым DNS-over-HTTPS-резолвером.
- Сервер, правила и DNS можно менять при подключённом туннеле: Rosetun перезапускает его за секунду-две без отключения, а kill switch в это время блокирует трафик.
- **Временные правила:** добавьте правило только до отключения; оно применяется сразу и никогда не сохраняется.
- **Автоматическое переподключение** после сна и падения ядра, сторож DNS при подключённом туннеле.
- **Проверки серверов:** пинг TCP (время соединения) и проверка URL с запросом через каждый сервер, в том числе при подключённом туннеле.
- Трей, **Запускать вместе с Windows**, интерфейс на русском и английском.

## Установка

Скачайте установщик на странице [Releases](https://github.com/eoftgge/rosetun/releases). Нужна Windows 10 или 11, x64. Установщик пока не подписан: если SmartScreen показывает «Windows protected your PC», нажмите **More info**, затем **Run anyway**.

После удаления программы настройки остаются в `%APPDATA%\Rosetun`.

### Проверка загрузки

Сравните результат `Get-FileHash .\rosetun-<version>-setup.exe -Algorithm SHA256` со строкой в `SHA256SUMS.txt` из релиза. Для публичного релиза по тегу проверьте происхождение командой `gh attestation verify .\rosetun-<version>-setup.exe --repo eoftgge/rosetun`.

## Приватность и сетевые обращения

Rosetun обращается в сеть следующим образом:

- К VPN-серверу для туннеля; **Пинг TCP** также пробует установить TCP-соединение с каждым проверяемым сервером при отключённом туннеле.
- **Проверка URL** и замер задержки текущего сервера на главном экране отправляют по одному HTTPS-запросу к `https://cp.cloudflare.com/generate_204` через проверяемый или текущий сервер. Проверка URL соединяется с каждым сервером напрямую, мимо туннеля.
- К провайдеру подписки для загрузки и обновления серверов. По умолчанию отправляется `User-Agent: Rosetun/<версия>`. Если включена **Отправка ID устройства**, запрос также содержит `x-hwid`, `x-device-os`, `x-ver-os` и `x-device-model`. Ссылка подписки может содержать пароль; при HTTP-подписке токен передаётся без шифрования.
- К настроенному DNS-over-HTTPS-резолверу через туннель. При подключении служба также проверяет DNS запросом `example.com`, а во время соединения задаёт вопросы о случайных именах под `example.com`.
- К `https://1.1.1.1/cdn-cgi/trace` через туннель, чтобы показать страну и внешний IP на экране подключения. Внешний IP по умолчанию скрыт и не записывается в журнал.
- Если DNS перестаёт отвечать, сторож отправляет HTTP-запрос `HEAD` к `1.1.1.1:80` через туннель, чтобы отличить сбой DNS от потери связи.
- До подключения системный DNS разрешает имя VPN-сервера; операционная система также может разрешать имена провайдера и серверов при проверке пинга.
- При смене сервера во время подключения имя нового сервера определяется через текущий туннель.

С локальным API ядра программа общается только через loopback. Телеметрии, проверки обновлений приложения и учётных записей Rosetun нет. Журналы остаются на этом компьютере; журнал службы доступен только администраторам. Адреса сайтов попадают в журнал лишь при временно включённом **Подробном журнале**. Автоматическое обновление *подписок* не означает обновление приложения.

## Как это устроено

```text
GUI (пользователь) ──именованный канал──► Служба Rosetun (SYSTEM) ──► sing-box.exe ──► TUN
                                               └── WFP: kill switch / замок DNS
```

Защитой владеет служба, поэтому закрытие GUI её не снимает. Если сама служба упала, Windows удаляет её фильтры (fail-open). Это нужно, чтобы компьютер не остался без сети навсегда.

## Сборка из исходников

Нужен Rust 1.96 или новее с MSVC под Windows. `cargo build --release` собирает программы, `cargo test --workspace` запускает тесты. Сборка пакета описана в [инструкции к установщику](installer/README.md), проверка с повышенными правами - в [описании стенда VM](tools/README.md).
